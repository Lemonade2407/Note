# 数据结构概论
## 数据结构的概念
### 数据与数据结构
- 数据：信息的载体，式描述客观事物的数、字符，以及所有能输入计算机中并被计算机程序识别和处理的符号的集合。
	- 数值型数据：整数、浮点数、复数、双精度数
	- 非数值型数据：字符、字符串
- 数据元素是数据的基本单元，由若干的数据项组成
- 数据项：
	- 初等项：不可再分
	- 组合项：可再分
- 结构：数据元素间的关系
- 数据结构：由某一数据元素的集合和该集合中的数据元素之间的关系组成，记为Data_Structure={D,R}
### 数据结构的分类
- 线性结构
- 非线性结构
	- 层次结构
	- 群结构
## 算法定义
- 算法特性：有输入、有输出、确定性、有穷性、能行性

### 性能标准

### 顺序表的性能分析
- 搜索的平均数据比较次数：$ACN=\frac{1+n}{2}$

- 存储利用率高、存取速度快

# 数组、串与广义表
## 多维数组
- 数组是下标和值组成的序对的集合，值称为数组元素
- $a[n][m]$：n行m列的数组
- 二维数组元素 $a[j][k]$ 的地址：$LOC=a[0][0]+j*m+k$
- 三维数组 $a[n][m][l]$ 元素 $a[i][j][k]$ 的地址：$LOC=a[0][0][0]+i*m*l+j*l+k$
## 特殊矩阵
### 对称矩阵的压缩存储
- 对于$n\times n$的对称矩阵，只需存储$\frac{n(n+1)}{2}$个元素
- 用一维矩阵存储$a[i][j]$
	- 下三角：$LOC=(i+1)*i/2+j$
	- 上三角：$LOC=(2n-i-1)*i/2+j$
## 稀疏矩阵
### 稀疏矩阵及其三元组数组表示
- 稀疏矩阵：非零元素个数<<零元素个数，且分布无规律
- 稀疏因子：$\delta =\frac{t}{m\times n}$，t为非零元素个数，m、n为矩阵行列数，$\delta<0.05$认为矩阵稀疏
- 三元组：$<row,column,value>$

## 广义表
### 广义表的定义和性质
- 简称表，是线性表的扩展；记作$LS=(a_0,a_1,...,a_n)$，第一个元素为表头，剩余元素组成的表为表尾
- 广义表允许表中有表
- 性质：有次序行、有长度、有深度、可递归、可共享
- ![[广义表示意图.png]]
### 广义表的表示
- 一般用链表结构作为存储表示![[广义表的存储表示.png]]
- 表节点组成：标志域+信息域+尾指针域
	- 标志域：
		- 0：头节点
		- 1：原子节点
		- 2：子表节点
	- 信息域：
		- 标志域为0时：引用计数
		- 标志域为1时：存放数据值
		- 标志域为2时：子表表头指针
	- 尾指针域：
		- 标志域0时：存放指向改表表头元素节点的指针
		- 标志域不为0时：存放下一个表节点的地址
- 广义表的长度：除头节点以外最高一层表的节点个数
# 树
## 树
### 树的定义和术语
- 自由树：是连通图
- 有根树：子树也是有根树，根有1个前驱和n个后继
- 结点：包含数据和指向其他结点的分支
- 结点的度：结点的子树棵数
- 祖先节点：根节点到该节点所经过的所有节点
- 树的度：树中结点的度的最大值
## 二叉树
### 二叉树的性质
- 第i层最多有$2^{i-1}$个结点
- 深度为k的二叉树最少k个结点，最多$2^k-1$个结点
- 非空二叉树的叶节点数为$n_0$，度为2的非叶节点数为$n_2=n_0-1$
- 满二叉树与完全二叉树：![[满二叉树与完全二叉树.png]]
- n个结点的完全二叉树的深度为$log_2(n+1)$
- 完全二叉树转换为一维数组
	- 结点i的父节点为i/2
	- 左子女为2i；右子女为2i+1
	- 结点i所在层次为$log_2i$+1

## 排序算法的选择策略
在实际应用中，选择合适的排序算法需要考虑以下因素：
1. 数据规模
    - **小规模数据**（n < 50）：可以使用简单排序算法，如插入排序
    - **中等规模数据**（50 ≤ n < 1000）：推荐使用快速排序或归并排序
    - **大规模数据**（n ≥ 1000）：优先考虑快速排序、归并排序或堆排序
2. 数据特征
    - **基本有序**：插入排序效率较高
    - **数据分布均匀**：快速排序效率较高
    - **数据范围较小**：计数排序或桶排序可能更高效
    - **数据有大量重复**：三路快速排序或计数排序更合适
3. 环境约束
    - **空间限制**：选择原地排序算法
    - **稳定性要求**：选择稳定排序算法
    - **硬件环境**：考虑缓存友好性和并行化潜力
4. 实际应用场景
    - **系统排序**：通常使用快速排序或归并排序的混合算法
    - **外部排序**：使用归并排序
    - **实时系统**：优先考虑时间复杂度稳定的算法
    - **内存受限环境**：选择空间复杂度低的算法
## 插入排序
```
void insertionSort(vector<int>& arr){
    for(int i=1;i<arr.size();i++){
        int temp=arr[i];
        int j=i-1;
        while (j >= 0 && arr[j] > temp) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = temp;
    }
}
```
