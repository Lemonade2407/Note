# 数据结构概论
## 数据结构的概念
### 数据与数据结构
- 数据：信息的载体，式描述客观事物的数、字符，以及所有能输入计算机中并被计算机程序识别和处理的符号的集合。
	- 数值型数据：整数、浮点数、复数、双精度数
	- 非数值型数据：字符、字符串
- 数据元素是数据的基本单元，由若干的数据项组成
- 数据项：
	- 初等项：不可再分
	- 组合项：可再分
- 结构：数据元素间的关系
- 数据结构：由某一数据元素的集合和该集合中的数据元素之间的关系组成，记为Data_Structure={D,R}
### 数据结构的分类
- 线性结构
- 非线性结构
	- 层次结构
	- 群结构

# 数组、串与广义表
## 多维数组
- 数组是下标和值组成的序对的集合，值称为数组元素
- $a[n][m]$：n行m列的数组
- 二维数组元素 $a[j][k]$ 的地址：$LOC=a[0][0]+j*m+k$
- 三维数组 $a[n][m][l]$ 元素 $a[i][j][k]$ 的地址：$LOC=a[0][0][0]+i*m*l+j*l+k$
## 特殊矩阵
### 对称矩阵的压缩存储
- 对于$n\times n$的对称矩阵，只需存储$\frac{n(n+1)}{2}$个元素
- 用一维矩阵存储$a[i][j]$
	- 下三角：$LOC=(i+1)*i/2+j$
	- 上三角：$LOC=(2n-i-1)*i/2+j$
## 稀疏矩阵
### 稀疏矩阵及其三元组数组表示
- 稀疏矩阵：非零元素个数<<零元素个数，且分布无规律
- 稀疏因子：$\delta =\frac{t}{m\times n}$，t为非零元素个数，m、n为矩阵行列数，$\delta<0.05$认为矩阵稀疏
- 三元组：$<row,column,value>$

# 树
## 树
### 树的定义和术语
- 自由树：是连通图
- 有根树：子树也是有根树，根有1个前驱和n个后继
- 结点：包含数据和指向其他结点的分支
- 结点的度：结点的子树棵数
- 祖先节点：根节点到该节点所经过的所有节点
- 树的度：树中结点的度的最大值
## 二叉树
### 二叉树的性质
- 第i层最多有$2^{i-1}$个结点
- 深度为k的二叉树最少k个结点，最多$2^k-1$个结点
- 非空二叉树的叶节点数为$n_0$，度为2的非叶节点数为$n_2=n_0-1$
- 满二叉树与完全二叉树：![[满二叉树与完全二叉树.png]]
- n个结点的完全二叉树的深度为$log_2(n+1)$
- 完全二叉树转换为一维数组
	- 结点i的父节点为i/2
	- 左子女为2i；右子女为2i+1
	- 结点i所在层次为$log_2i$+1

## 散列（Hash table）
### 散列表与散列方法
- Address=Hash(key)，通过映射储存、访问key
- 不同key映射到相同的Address上称为冲突
- Address相同的不同key为同义词
### 散列函数
- 散列函数要求：
	- 定义域必须包括需要存储的全部关键码
	- 结果域均匀分布到整个地址空间中
	- 函数必须是简单的，计算时间短
- 常用散列函数
	- 除留余数法：
		- 设地址数为m，取≤m（接近m）的质数p作为除数
		- Hash(key)=key%p
	- 数字分析法：
		- 仅适合事先知道key集合
		- 均匀度$\lambda_k =\sum^r_{i=1}(\alpha^k_i-n/r)^2$,对于n个d位数，r为每位的符号种类数，$\alpha_i^k$为第i个符号在第k位上出现的次数
	- 平方取中法
	- 折叠法
### 处理冲突的闭散列方法（开地址法）
- 改造散列表，对于m个地址，改造为m个桶，每个桶存s个元素，桶内元素少。桶号=Address
- 闭散列法：桶在环形数组中，s=1，冲突的元素放在空桶中，寻找空桶的方式如下
	- 闭散列法适合不经常变动的表
	- 线性探查法：
		- 每当发生冲突，寻找相邻的下一个桶
		- 易产生堆积问题：不同探查序列互相穿插，增加搜索时间
	- 二次探查法：
		- 下一个桶号的计算公式：$H_i=(H_0+i^2)$%m、$H_i=(H_0-i^2)$%m
		- 当表的长度为质数且表的装载因子≤0.5时，新表项一定能插入
	- 双散列法：
		- 发生冲突后用第二个散列函数ReHash()计算到达下一个桶的偏移量，取值应该是小于地址空间且与地址空间互质的正整数
	- 搜索性能：平均搜索长度ASL
		- 成功平均搜索长度$ASL_{succ}$：搜索已有元素的探查次数平均值
		- 失败平均搜索长度$ASL_{unsucc}$：找到空桶的探查次数平均值
### 处理冲突的开散列法（链地址法）
- 桶中元素用单链表链接，称为同义词子表
- 以搜索平均长度为n/m的子表代替搜索长度为n的顺序表
### 散列表分析
- 开散列法>闭散列法
- 除留余数法>其他>折叠法
- 装载因子$\alpha=\frac{已有记录数n}{最大记录数m}$

# 搜索结构
- 基于key的搜索法，结果唯一
- 基于属性的搜索法，结果不唯一
- 衡量搜算算法的时间效率标准：ASL
## 静态搜索
### 顺序搜索
- $ASL_{succ}=\sum^{n-1}_{i=0}p_i\bullet c_i$
- 当$p_i$相等时，$ASL_{succ}=\frac{n+1}{2}$
- 时间复杂度：$O(n)$
### 二分搜索
- 基于有序顺序表
- 时间复杂度：$O(log_2n)$
## 二叉搜索树
### 二叉搜索树的概念
- 每个节点有作为搜索依据的key
- 左子树<根节点<右子树
- 左右子树也是二叉搜索树
### 二叉搜索树的搜索
![[二叉搜索树的搜索.png]]
- 比较次数不超过树高h
### 二叉搜索树的插入
- ![[二叉搜索树的插入.png]]
- 每次插入都要从根节点搜索插入位置
### 二叉搜索树的删除
- 叶节点：直接删除
- 只有左/右节点：左/右结点直接顶替
- 左右结点不为空：在右子树中寻找可以顶替的结点
- ![[二叉搜索树的删除算法.png]]
### 二叉搜索树的性能分析
- 对于n个key，可以构成$\frac{1}{n+1}C^n_{2n}$个二叉搜索树
- $ASL_{succ}=\sum^n_{i=1}p[i]\times le[i]$，$p[i]$：权值，$le[i]$：搜索该节点所需比较次数
- $ASL_{unsucc}=\sum^n_{i=1}q[i]\times (le[i]-1)$
- $ASL=ASL_{succ}+ASL_{unsucc}$
- 对于搜索概率相等的情况：
	- $ASL_{succ}=\frac{1}{n}\sum^n_{i=1}log_2i$
	- $ASL_{unsucc}=\frac{1}{n+1}\sum^n_{i=1}log_2i$
- 对于搜索概率不相等的情况：搜插删的平均给时间代价为$O(log_2n)$
## AVL树
### AVL树的概念
- 高度平衡的二叉搜索树（左右子树高度差不超过1）
- 平衡因子bf：该节点右子树高度减左子树高度，若bf绝对值大于1，则失衡
### 平衡化旋转
- 若不平衡节点与上两层结点在直线上，则单旋转；若在折线上，则双旋转
- 左单旋转：![[左单旋转.png]]![[左单旋转算法.png]]
- 右单旋转：![[右单旋转.png]]
- 先左后右双旋转：![[先左后右双旋转.png]]![[先左后右双旋转算法.png]]
- 先右后左双旋转：![[先右后左双旋转.png]]
### AVL树的插入
- 新插入结点p
- 修改p到root的路径上所有结点的bf
- 检查p的父节点$p_r$的bf：
	- bf=0：结束平衡化
	- |bf|=1：继续考察$p_r$的父节点
	- |bf|=2：
		- bf=2
			- 右子树bf=1：左单
			- 右子树bf=-1：先右后左
		- bf=-2
			- 左子树bf=1：先左后右

## 红黑树
### 红黑树的概念和性质
- 自平衡二叉搜索树，减少了旋转次数，适合大量插入/删除的场景
- 特性：
	- 根节点和叶节点是黑色
	- 根节点到叶节点没有连续的红色节点
	- 根节点到叶节点的黑色节点数目相同
- 任意结点x到达叶节点的路径经过的黑结点个数称为x的黑高度，也称作结点的阶，记作bh(x)
- 根结点到叶节点的路径长度PL为该路径上指针的个数，则对于路径P、Q，$PL(P)<=2PL(Q)$
- 设红黑树高度为h，n个非叶结点，根节点黑高度为r
	- $h≤2r$
	- $n≥2^r-1$
	- $h≤2log_2(n+1)$

## 排序算法的选择策略
在实际应用中，选择合适的排序算法需要考虑以下因素：
1. 数据规模
    - **小规模数据**（n < 50）：可以使用简单排序算法，如插入排序
    - **中等规模数据**（50 ≤ n < 1000）：推荐使用快速排序或归并排序
    - **大规模数据**（n ≥ 1000）：优先考虑快速排序、归并排序或堆排序
2. 数据特征
    - **基本有序**：插入排序效率较高
    - **数据分布均匀**：快速排序效率较高
    - **数据范围较小**：计数排序或桶排序可能更高效
    - **数据有大量重复**：三路快速排序或计数排序更合适
3. 环境约束
    - **空间限制**：选择原地排序算法
    - **稳定性要求**：选择稳定排序算法
    - **硬件环境**：考虑缓存友好性和并行化潜力
4. 实际应用场景
    - **系统排序**：通常使用快速排序或归并排序的混合算法
    - **外部排序**：使用归并排序
    - **实时系统**：优先考虑时间复杂度稳定的算法
    - **内存受限环境**：选择空间复杂度低的算法
