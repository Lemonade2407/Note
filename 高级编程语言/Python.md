# 数据类型
### 数字类型
- int、float、complex
#### 整数类型（int）

| 进制   | 引导符号(不区分大小写) |
| ---- | ------------ |
| 十进制  | 无            |
| 二进制  | 0b           |
| 八进制  | 0o           |
| 十六进制 | 0x           |
- pow(x,y)：计算$x^y$
#### 浮点类型（float、double）
- 科学计数法：$<a>e<b>=a*10^b$
- round(x,d)：对x四舍五入，d为小数截取位
- 高精度浮点运算：decimal库
- 定义：`a = decimal.Decimal('高精小数')`
- 自定义位数：`decimal.getcontext().prec = 位数`
#### 复数类型（complex）
- 虚部通过后缀“J”或“j”表示
- 对于复数z，`实部 = z.real 虚部 ＝ z.imag`
### 数字类型的操作
#### 运算操作符
整数除：`x//y`
幂运算：`x**y`
#### 运算函数

| 函数         | 描述          |
| ---------- | ----------- |
| abs(x)     | x的绝对值       |
| pow(x,y,z) | x**y%z      |
| roud(x,n)  | x四舍五入保留n位小数 |

### 字符串类型及其操作
#### 字符转义
- “\b”：回退
- "\n"：换行
- “\r”：回车
- 在字符串前加r指定原始字符串
#### 符号体系
- 正向递增序号：字符串从左到右，序号从0递增
- 反向递减序号：字符串从右到左，序号从-1递减
#### 操作符
- 切片：`str[N:M:K]`,左闭右开，N,M可缺失，K为步长
- 连接字符串：`x+y`
- 复制n次字符串：`x*n或n*x`
- 判断是否是子串：`x in s`

#### 操作函数

| 函数     | 描述   |
| ------ | ---- |
| len(x) | 返回长度 |
#### 处理方法

| 方法                         | 描述                                |
| -------------------------- | --------------------------------- |
| str.split(sep,maxsplit)    | 返回一个列表，包含str根据sep分割的部分            |
| str.strip(chars)           | 返回str，两侧去掉chars中列出的字符             |
| str.center(width,fillchar) | 返回长度为width的字符串，str居中，两侧填充fillchar |
| str.zfill(width)           | 返回长度为width的字符串，str不足部分左侧填0        |
| str.format()               | str中用占位符{顺序编号}占位，方法中参数按顺序填充       |
#### 格式化
- 占位符％法：同C语言
- format格式化法：
	- `<模板字符串>.format(<参数1，参数2>，...)`模板字符串中用{}占位，称为槽
	- 槽的配置：`{<参数序号>:<格式控制标记>}`
	- 格式控制标记：
		- 填充：用于补齐长度的字符
		- 对齐：
			- <：左对齐
			- >：右对齐
			- ^：居中对齐
		- 宽度
		- ,：数字千分位分隔符
		- .n：数字精度或字符串长度
		- 数字类型：b、c、d、o、x...
- F string法：`f'{}'’
### 序列
- 有顺序，元素可以相同，元素类型可以不同
- 是基类类型，衍生类型有字符串、元组和列表
- `ord()`：将ASCII字符转为数值
- `chr()`：将数值转换为ASCII字符
#### 列表
- 使用[]或list()创建
- 列表中元素类型可不同
- 创建后可随意修改，是可变数据类型
- `del ls[i]`：删除列表第i个元素
- `del ls[i:j:k]`：删除列表中第i到第j步长为k的元素
- `ls.append(x)`：列表尾插x元素
- `ls.clear()`：清空列表
- `ls.copy()`：生成新列表，赋值ls的元素
#### 元组
- 元素写在()中，()可省略，且位置和值不可修改
- 使用tuple()创建
### 集合
- 不可变数据类型，元素唯一，数据类型可不同
- 用{}或set()创建
### 字典
- 无序的键值对对象集合
- key唯一且不可变
- 用{}或dict()创建，:表示键值对
- `value=dict[key]`
- `dict[key]=value`
- `dict.get(key,default)`：key存在则返回对应value，不在返回default

# 程序结构
## 分支结构
```
if 条件1:
	语句块1
elif 条件2:
	语句块2
else:
	语句块n
```
## 循环结构
### 遍历循环
```
for 变量 in 遍历结构:
	语句块
else:
	正常结束后语句
```
常见用法
```
遍历N次，从1～(N-1)
for i in range(N):
	语句块
```
### 无限循环
```
while 条件:
	语句块
else:
	正常结束后语句
```
## 异常处理
```
try：
	语句块
except 异常类型1:
	语句块
except:
	语句块	
finally：
	无论是否报错都执行的语句块
```

# 文件和数据格式化
## 开关文件
### 打开文件
`变量名 = open(文件名,打开模式)`

| 文件打开模式 | 含义           |
| ------ | ------------ |
| r      | 只读           |
| w      | 覆写           |
| x      | 若不存在文件则创造，写入 |
| a      | 追加写入         |
| b      | 二进制          |
| t      | 文本文件         |
打开模式可用＋叠加多种模式
### 关闭文件
`变量名.close()`
## 读写文件

| 操作方式                  | 含义              |
| --------------------- | --------------- |
| `变量名.readall()`       | 读入所有内容          |
| `变量名.read(size)`      | 读入前size长度的内容    |
| `变量名.readline(size)`  | 读入一行前size长度的内容  |
| `变量名.readlines(hint)` | 读入hint/所有行，返回列表 |
常用逐行处理
```
for line in file
	print(line)
```
